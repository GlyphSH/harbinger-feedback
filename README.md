# Harbinger feedback

Corrections and questions for the [Harbinger feed](https://glyph.sh/feed/), an
exploitation early-warning list of CVEs ranked by a model and shown with their
public evidence.

Open an issue to:

- report a wrong fact on a CVE row (evidence, dates, links, vendor flags)
- ask for a correction or retraction
- ask a question about the method ([glyph.sh/feed/methodology](https://glyph.sh/feed/methodology))

Please do not post exploit code, unpatched vulnerability details, or anything
under embargo. This repository holds issues only; the feed's code is private.
